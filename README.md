# DAHAB — Coast. Marine. Desert Gold.

A responsive UX/UI website concept built from the supplied Dahab source material and six supplied images.

## Open
Double-click `index.html` or serve the folder with any static web server.

## Structure
- `index.html` — complete responsive website
- `assets/` — all supplied images renamed for clean web paths

## Design direction
- Deep Red Sea navy + turquoise for marine content
- Sand / gold palette for desert and Bedouin culture
- Large editorial typography
- Scroll-reveal motion
- Responsive mobile layout
- Sections: Place, History, Marine attractions, Intangible heritage
